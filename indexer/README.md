# indexer
This directory contains the **indexer** subsystem for Lab 5 of the CS50 Tiny Search Engine.

## Overview

`indexer` builds an index from files in a page directory generated by the crawler. It allows for efficient lookup of words across documents by mapping each word to the documents where it occurs and the count of occurrences in that document. 

## Files

- **`indexer.c`** – implements  
  - `indexBuild(...)`  
- **`indextest.c`** - test file for index and indexer by calling index_save()
- **`Makefile`** – builds and links against `common.a` and `libcs50-given.a`  
- **`testing.sh`** – functional tests for error cases and valid crawls  
- **`.gitignore`** – ignores object files, executable, and test outputs

## Build

```bash
cd indexer
make          # builds `indexer`
```

## Usage
```./indexer pageDirectory indexFilename```

## Assumptions

testing.sh assumes ../crawler/testing.sh has been run
